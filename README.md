# FitManager 🏋️

### سامانه مدیریت باشگاه ورزشی

یک برنامه‌ی دسکتاپ ساده برای مدیریت اطلاعات باشگاه ورزشی که با استفاده از پایتون و کتابخانه‌ی Tkinter توسعه داده شده است.

## 📌 درباره پروژه

FitManager یک برنامه‌ی مدیریت باشگاه ورزشی است که امکان مدیریت مربیان، ورزشکاران، برنامه‌های تمرینی و حرکات ورزشی را از طریق یک رابط گرافیکی فراهم می‌کند.

این پروژه با هدف تمرین و تقویت مهارت‌های برنامه‌نویسی پایتون، به‌ویژه برنامه‌نویسی شیءگرا و توسعه‌ی رابط کاربری گرافیکی، طراحی شده است.

## ✨ امکانات

* **مدیریت مربیان:** افزودن، ویرایش، مشاهده و حذف اطلاعات مربیان
* **مدیریت ورزشکاران:** ثبت و مدیریت نام، سن و مربی هر ورزشکار
* **مدیریت برنامه‌های تمرینی:** ایجاد و مدیریت برنامه‌های تمرینی ورزشکاران
* **مدیریت حرکات ورزشی:** ثبت و مدیریت نام حرکت، تعداد ست، تعداد تکرار و وزن
* **رابط کاربری گرافیکی:** کار با برنامه از طریق پنجره‌ها، دکمه‌ها و جدول‌های گرافیکی
* **اعتبارسنجی اطلاعات:** بررسی برخی ورودی‌های کاربر پیش از ثبت اطلاعات

## 🛠️ فناوری‌های استفاده‌شده

* Python
* Tkinter
* برنامه‌نویسی شیءگرا (OOP)

## 📁 ساختار پروژه

```text
FitManager/
├── main.py       # نقطه شروع و اجرای برنامه
├── models.py     # تعریف کلاس‌های اصلی
├── manager.py    # مدیریت اطلاعات و عملیات اصلی
├── gui.py        # طراحی رابط کاربری گرافیکی
└── README.md     # مستندات پروژه
```

## 🚀 نحوه اجرا

### پیش‌نیازها

* نصب Python نسخه ۳
* در دسترس بودن کتابخانه Tkinter در محیط پایتون

### مراحل اجرا

۱. مخزن پروژه را از گیت‌هاب دریافت کنید یا پوشه پروژه را دانلود کنید.

۲. پوشه پروژه را در محیط برنامه‌نویسی خود باز کنید.

۳. ترمینال را در مسیر پوشه پروژه باز کرده و دستور زیر را اجرا کنید:

```bash
python main.py
```

در بعضی سیستم‌ها، لازم است از دستور زیر استفاده کنید:

```bash
python3 main.py
```
